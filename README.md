# CHROMA — прототип для геймджема (Phaser 3)

Веб-игра под мобилки на **Phaser 3**. Без сборщиков и npm — просто открывается в браузере. Работает офлайн (Phaser лежит локально в `lib/`).

## Что внутри

- Стартовое меню: кампания, обучение, лаборатория, скины, настройки
- Коргеймплей: Xonix 360° + нарезка поля (Clipper.js) + пробирки + враги и боссы
- 30 уровней кампании, 7 обучающих и 9 лабораторных черновиков
- Уровни из `levels/levels.json` в паках `campaign` / `training` / `lab` (см. `LEVELS.md`)
- История версий и техническая памятка: `VERSION_HISTORY.md`
- Пауза, настройки (в том числе сброс прогресса), процедурные звуки
- Бустеры, типы врагов, скины за победы в кампании
- Три типа боссов: `bulletHell`, `fieldBoss`, `colorBoss`; тестовый rewarded-ad адаптер
- Адаптив 720×1280 FIT, лимит 80 МБ

## 1. Локальный запуск

Открывать `index.html` двойным кликом **нельзя** — из-за `file://` браузер заблокирует загрузку скриптов. Нужен локальный веб-сервер. Проще всего через Python (у тебя он уже установлен).

В папке проекта запусти:

```bash
python -m http.server 8001
```

Затем открой в браузере:

```
http://localhost:8001
```

Остановить сервер — `Ctrl + C` в терминале.

### QA-режим

Открой `http://localhost:8001/?qa=1`. В выборе уровней временно разблокируются
все уровни, но сохранённый прогресс не изменяется. Жёлтая метка `QA MODE`
показывает, что режим активен.

Перед тестированием уровней запусти:

```bash
python tools/validate_levels.py
python tools/validate_modules.py
```

Валидатор проверяет JSON-контракт, координаты, цвета, запас для пробирок,
типы врагов, бустеры, магнитные пути, боссов и наличие SVG. Вторая проверка
ловит отсутствующие JS-файлы и неверные именованные импорты ES-модулей.

### Проверить на телефоне (по локальной сети)

1. Узнай IP компьютера. В PowerShell:

```bash
ipconfig
```

   Возьми `IPv4-адрес` (например `192.168.1.42`).

2. Запусти сервер так, чтобы он был виден в сети:

```bash
python -m http.server 8001 --bind 0.0.0.0
```

3. На телефоне (в той же Wi-Fi-сети) открой:

```
http://192.168.1.42:8001
```

> Если не открывается — скорее всего мешает брандмауэр Windows. Разреши Python доступ к частной сети, когда выскочит запрос.

## 2. Публикация на GitHub Pages

### Вариант А — через сайт GitHub (без командной строки)

1. Создай новый репозиторий на github.com (например `my-game`), Public.
2. На странице репозитория нажми **Add file → Upload files** и перетащи туда **всё содержимое этой папки** (файлы `index.html`, папки `css`, `js`, `lib`). Commit.
3. **Settings → Pages** → в разделе *Build and deployment*:
   - Source: **Deploy from a branch**
   - Branch: **main**, папка **/ (root)** → **Save**.
4. Через 1–2 минуты игра будет по адресу:

```
https://<твой-логин>.github.io/my-game/
```

### Вариант Б — через git (командная строка)

```bash
git init
git add .
git commit -m "Game jam boilerplate"
git branch -M main
git remote add origin https://github.com/<твой-логин>/my-game.git
git push -u origin main
```

Затем включи Pages как в шаге 3 варианта А.

> **Важно:** пути к файлам в проекте относительные (`js/...`, `lib/...`), поэтому на GitHub Pages в подпапке `/my-game/` всё загрузится корректно. Ничего править не нужно.

## 3. Структура проекта

```
index.html            — точка входа, подключает все скрипты
css/style.css         — стили страницы (fullscreen, без прокрутки)
lib/phaser.min.js     — движок Phaser (локально, офлайн)
js/
  settings.js         — сохранение настроек и прогресса (localStorage)
  audio.js            — процедурная музыка и звуки (Web Audio API)
  background.js        — анимированный фон
  ui/Button.js         — кнопка (наведение/нажатие/звук)
  ui/Slider.js         — слайдер громкости
  scenes/
    BootScene.js       — старт
    PreloadScene.js    — экран загрузки (сюда грузить будущие ассеты)
    MenuScene.js       — главное меню
    HowToScene.js      — «Как играть»
    SettingsScene.js   — настройки
    LevelSelectScene.js— выбор уровня
    GameScene.js       — координация игрового цикла
    UIScene.js         — HUD, пробирки и rewarded-меню
    PauseScene.js      — меню паузы
  managers/            — поле, пробирки, враги, боссы, цели и награды
  entities/            — игрок, враги, снаряды, пробирки и бустеры
  utils/               — геометрия и адаптер Clipper
  main.js              — конфиг игры и запуск
```

## 4. Основные точки расширения

- Контент уровней — `levels/levels.json` и `LEVELS.md`.
- Новые игровые системы — отдельные менеджеры в `js/managers/`.
- UI — `UIScene`, меню и переиспользуемый `UIButton`.
- Реальная реклама — замена `TestRewardedAdapter` в `RewardedAdManager`.
- Ассеты — `assets/` с загрузкой через `PreloadScene`.

> Лимит веса билда на джеме — 80 МБ. Сейчас проект весит ~1.2 МБ (только Phaser),
> так что запас под ассеты огромный. Держи картинки в атласах, звук в OGG/MP3.

## Сброс прогресса/настроек

В игре: **Настройки → Сброс прогресса** (подтверждение вторым нажатием).
Сбрасываются прохождения, разблокировки и выбранный скин; громкость не трогается.

Полный сброс, включая аудио, из консоли браузера (F12):

```js
GameSettings.reset(); location.reload();
```
