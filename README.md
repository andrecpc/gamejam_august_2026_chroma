# CHROMA

Мобильная портретная веб-игра на **Phaser 3**: нарезай цветное поле и комкай куски в корзины. Сборщика и npm нет — открывается в браузере. Phaser и Clipper лежат локально в `lib/`.

Актуальная сборка: **paper cut v1.7.5**.

## Играть

- Управление: зажми палец — точка едет в эту сторону.
- С рамки заезжай в цвет и возвращайся на стену. Отрезанный кусок падает в корзину своего цвета.
- Не пересекай свой хвост. Касание врага снимает жизнь.
- Сначала проходится **обучение** (7 уровней). **Кампания** (30 уровней) открывается только после него.
- Скины открываются победами в кампании.
- При проигрыше можно один раз за попытку посмотреть рекламу: **+1 сердце**, **+1 срез** или **+15 секунд** — в зависимости от того, почему уровень провален.

Прогресс хранится в `localStorage`. Сброс: **Настройки → Сброс прогресса**.

## Локальный запуск

`index.html` нельзя открывать двойным кликом (`file://` блокирует модули). Нужен локальный сервер.

```bash
python -m http.server 8001 --bind 127.0.0.1
```

Затем открой [http://127.0.0.1:8001](http://127.0.0.1:8001). Остановить сервер — `Ctrl+C`.

После обновления файлов делай жёсткое обновление страницы (**Ctrl+F5**).

### Телефон в той же Wi‑Fi сети

```bash
python -m http.server 8001 --bind 0.0.0.0
```

На телефоне открой `http://<IPv4-компьютера>:8001` (IPv4 смотри в `ipconfig`). Если не открывается — разреши Python в брандмауэре Windows.

### Проверка уровней (необязательно)

```bash
python tools/validate_levels.py
python tools/validate_modules.py
```

## Структура

```
index.html              точка входа
css/style.css           fullscreen, safe-area
assets/paper/           текстуры стола и крафта
lib/phaser.min.js       Phaser 3
lib/clipper.js          нарезка полигонов
levels/levels.json      кампания, обучение, черновики
js/
  main.js               конфиг 720×1280 FIT
  paper.js              бумажный визуал
  settings.js           прогресс и настройки
  audio.js              процедурные звуки
  scenes/               меню, игра, HUD, пауза
  managers/             поле, корзины, враги, боссы, цели
  entities/             игрок, враги, корзины, бустеры
tools/                  сборка и проверка уровней
```

Контракт уровней: `LEVELS.md`. История изменений: `VERSION_HISTORY.md`.
