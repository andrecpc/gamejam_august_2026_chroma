# Как делать уровни (SVG → JSON)

Игра читает **только** `levels/levels.json`. Уровни лежат в паках:

- `campaign` — основная игра, открывается по очереди;
- `training` — обучение, открывается по очереди; карточки `tutorials` показываются при каждом запуске уровня и висят, пока игрок не начнёт движение;
- `lab` — лаборатория черновиков (в меню игрока скрыта; уровни остаются в JSON для инструментов).

Кампанию и обучение пересобирает `tools/build_packs.py`. `id` уникален **внутри пака**.

SVG нужен как чертёж: нарисовал в Inkscape → прогнал скрипт → подправил пробирки руками. `svg_to_json.py` обновляет лабораторный уровень с тем же `sourceSvg` и не трогает обучение.

Рабочий холст игры: **720×1280**, поле: **x=40, y=130, ширина=640, высота=640**. Рамка «стены» (по ней ходит герой в начале) — **28 px** внутрь. Цветные куски рисуй **внутри** рамки, с `x≥68`, `y≥158`, `x+w≤652`, `y+h≤742`.

Шаблон уже лежит здесь: `levels/svg/01_template.svg`. Открой его в Inkscape и «Сохранить как копию» под именем `02_....svg`, `03_....svg` — номер в начале файла становится `id` уровня.

## Имена объектов (id или inkscape:label)

| Имя | Что это |
|---|---|
| `poly_red_1`, `poly_blue_2`, `poly_yellow_1`… | Цветной сегмент поля. Цвет берётся из середины имени: `red` / `blue` / `yellow` / `green` / `purple` / `orange` / `cyan` / `pink`. |
| `path_magnetic_1` | Магнитный контур (кривая). В MVP ещё не ездим по нему, но скрипт уже выгружает точки. |
| `spawner_enemy_pingpong` | Точка спавна врага. После `_` тип: пока живой только `pingpong`. Позже: `chase`, `turret`, `thief`, `laser`. |

Имя можно писать в поле **ID** объекта или в **Label** слоя Inkscape — скрипт смотрит оба.

Как назвать в Inkscape: выдели объект → `Object → Object Properties` → `Label` / `ID`.

## Что рисовать

- Прямоугольники, многоугольники, круги, эллипсы, пути Безье — всё ок.
- Кривые (`C` / `Q` в path) скрипт сам нарежет на ломаную (~14 точек на кубик).
- Один цвет можно разбить на несколько фигур: `poly_red_1` и `poly_red_2`.
- Не клади цветные куски на рамку — герой стартует снизу по чёрной рамке.

## Скрипт

Из папки `game_v6`:

```bash
python tools/svg_to_json.py
```

Он:

1. читает все `levels/svg/*.svg`;
2. обновляет геометрию, спавны врагов и магнитные пути;
3. **не затирает** `vials`, `lives`, `constraints`, `boosters`, если уровень с таким `id` уже был в JSON.

После прогона открой `levels/levels.json` и выставь пробирки.

## JSON: что править руками

```json
"vials": [
  { "color": "red" },
  { "color": "red" },
  { "color": "blue" }
]
```

Правила:

- 1 пробирка = **10%** стартовой площади всех цветных полигонов.
- Сумма пробирок обычно **не больше 70%** поля (для сложных — до 90%). Скрипт печатает оценку в консоль.
- На экране одновременно не больше **3** пробирок; остальные ждут в очереди.
- Overflow: лишний объём переливается только в **уже выставленную** пробирку того же цвета. Если следующей ещё нет внизу — кусок цвета остаётся на поле.
- Каждая видимая пробирка считается как `×1`. Если пробирки того же цвета
  скрыты в очереди, их число добавляется только к самой левой видимой
  пробирке этого цвета.
- Срез игрока отклоняется, если после него цвета останется меньше, чем нужно
  незаполненным пробиркам. На срезы подрезчика это ограничение не действует.
- Для каждого цвета оставляй минимум 5% запаса сверх суммарной вместимости
  его пробирок. При недостатке игра выводит предупреждение в консоль.

Враги:

```json
"enemies": [{ "type": "pingpong", "x": 220, "y": 420, "vx": 88, "vy": 64 }]
```

Доступные типы:

- `pingpong` — отскакивает внутри оставшегося цвета;
- `rover` — летает по всему полю, включая очищенные области;
- `chase` — преследует игрока по цвету, параметр `speed`;
- `turret` — стреляет, параметры `shotInterval`, `bulletSpeed`, `bulletLife`;
- `laser` — статичный луч, параметры `angle`, `length`, `interval`, `warning`,
  `activeTime`;
- `thief` — медленный подрезчик, постоянно оставляющий за собой вырезанный
  след шириной в собственный диаметр. Движется по всему полю, включая свой
  след, и начинает резать при создании, ещё до первого кадра движения. След
  становится безопасной стеной `claimed`, как срез игрока, и подходит для
  замыкания контуров. Визуально отдельной заливки стены нет: удалённый цвет
  открывает общий фон пустоты поля `#1a1f3d`, такой же, как после среза
  игрока. Параметры: `speed`, `drainStep`
  (частота обновления геометрии в пикселях) и `noticeInterval`.

Расширенный пример всех типов находится в лаборатории, уровень 4. После обработки SVG
скрипт обновляет тип и координаты спавна, но сохраняет параметры поведения.

Bullet-hell босс:

```json
"boss": {
  "type": "bulletHell",
  "x": 360, "y": 370, "health": 48,
  "attackInterval": 1800, "radialBullets": 8,
  "bulletSpeed": 100, "aimedEvery": 2,
  "towerDamage": 1, "towerFireInterval": 850,
  "towerSlots": [
    { "x": 95, "y": 185 },
    { "x": 625, "y": 185 }
  ]
}
```

Каждая лопнувшая пробирка создаёт башню в следующем `towerSlot`. Башни
автоматически стреляют в босса. После 50% здоровья радиальный залп становится
плотнее и быстрее. Снаряды босса и башен используют общий object pool.
Полный пример — лаборатория, уровень 8.

Босс как часть поля:

```json
"boss": {
  "type": "fieldBoss",
  "x": 360, "y": 430, "radius": 46,
  "attackInterval": 2300, "radialBullets": 6,
  "bulletSpeed": 82, "aimedEvery": 2,
  "nodes": [
    { "id": "leg_nw", "x": 190, "y": 270 },
    { "id": "leg_ne", "x": 530, "y": 270 }
  ]
}
```

Каждый узел-лапа удаляется, когда попадает в реально применённый срез игрока.
После удаления всех узлов ядро меняет обводку на зелёную. Ядро необходимо
захватить срезом. Если игрок изолировал ядро заранее, босс будет побеждён при
удалении последней лапы — уровень не может оказаться в непроходимом состоянии.
Ядро также выпускает радиальные и прицельные залпы; после потери половины
здоровья они учащаются. Каждая активная лапа разрешает стрельбу только в свою
четверть круга. После её отсечения соответствующий сектор становится
безопасным; без лап паук полностью прекращает огонь. Пример — лаборатория, уровень 9.

Цветной шар (`colorBoss`) — финал кампании, уровень 30:

```json
"boss": {
  "type": "colorBoss",
  "title": "СТРАЖ",
  "x": 360, "y": 450, "radius": 44,
  "moveSpeed": 52, "vx": 38, "vy": 30,
  "cutPercent": 0.5,
  "colors": ["red", "blue", "green"],
  "attackInterval": 2200, "radialBullets": 6,
  "aimedEvery": 2, "bulletSpeed": 88
}
```

Шар ездит по полю и стреляет. У него столько полосок HP, сколько цветов в
`colors`. Срез этого цвета уменьшает соответствующую полоску; `cutPercent` —
какая доля стартовой площади цвета нужна, чтобы обнулить полоску. Касание
шара бьёт как снаряд. Победа на 30-м — `winCondition: "all"` (пробирки и босс).

Rewarded-реклама:

- после потери последней жизни один раз за попытку доступно воскрешение с
  одной жизнью;
- кнопка `📺` во время игры ставит `GameScene` на паузу и показывает три
  случайных предложения;
- закрытие меню не меняет предложения;
- после успешного просмотра набор генерируется заново, повторы разрешены;
- награды: жизнь, удаление врага, случайный или конкретный бустер на поле,
  автоматическое заполнение одной из выставленных пробирок;
- сейчас используется `TestRewardedAdapter` с задержкой 1,4 секунды. Для
  подключения SDK достаточно заменить метод `show()` адаптера.

Бустеры и антибустеры:

```json
"boosters": [
  { "type": "speed", "x": 150, "y": 260, "duration": 6000, "multiplier": 1.45 },
  { "type": "slow", "x": 170, "y": 610, "duration": 4500, "multiplier": 0.62 },
  { "type": "shield", "x": 560, "y": 250, "duration": 6000 },
  { "type": "life", "x": 360, "y": 350, "amount": 1 },
  { "type": "enemySlow", "x": 550, "y": 610, "spawnDelay": 5000 },
  { "type": "mystery", "x": 360, "y": 660, "spawnDelay": 8000 }
]
```

`spawnDelay` задаётся в миллисекундах. `mystery` может получить массив
`outcomes` с вариантами выпадения. Полный пример находится в лаборатории, уровень 3.

Цели и ограничения уровня:

```json
"constraints": {
  "time": 75,
  "coverPercent": 35,
  "maxCuts": 5,
  "winCondition": "all"
}
```

- `time` — секунды до поражения;
- `coverPercent` — сколько процентов стартового поля должен срезать игрок;
- `maxCuts` — максимум успешных срезов;
- `winCondition: "vials"` — победа после всех пробирок;
- `winCondition: "coverage"` — победа по проценту поля;
- `winCondition: "catch"` — отсечь `catchEnemies` врагов контуром;
- `winCondition: "all"` — пробирки, покрытие, ловля и босс (что задано);
- `winCondition: "boss"` — победа только после уничтожения босса.

Пустые `{}` — старый режим без ограничений: победа после всех пробирок.
Примеры находятся в лаборатории, уровни 5–8, и в обучении, уровень 7.

## Проверка кривых (на будущее)

Если в фигуре цвета на 2.3 пробирки — в уровне должно быть **не больше 2** пробирок этого цвета. Остаток сам исчезнет, когда пробирки цвета закончатся.

## Слой фич (после MVP)

1. Управление 360° + хвост — **есть**
2. Clipper, нарезка — **есть**
3. Пробирки + overflow + волна жидкости — **есть**
4. Враг pingpong + огонь по хвосту — **есть**
5. JSON + SVG-пайплайн — **есть**
6. Магнитные контуры + snap — **есть** (обучение 5, кампания 5, лаборатория 2)
7. Бустеры / антибустеры / `?` — **есть** (обучение 6, кампания 6, лаборатория 3)
8. Типы врагов: rover, chase, turret, thief, laser — **есть** (кампания 4–10, лаборатория 4)
9. Ограничения уровня (время / % поля / число срезов) — **есть** (обучение 7, кампания 8–9, лаборатория 5–7)
10. Скины точки — **есть**
11. Босс bullet-hell + башни из пробирок — **есть** (кампания 11, лаборатория 8)
12. Босс-контур (паук) — **есть** (кампания 20, лаборатория 9)
13. Цветной шар `colorBoss` — **есть** (кампания 30)
14. Точки rewarded-рекламы — **есть тестовый адаптер**
